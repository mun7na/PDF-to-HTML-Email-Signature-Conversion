# PDF to HTML Email Signature Conversion

## Overview

This project demonstrates the conversion of a PDF email signature design into a functional HTML email signature.

The goal was to maintain the original design while making all elements interactive and compatible with email clients.

## Features

- Pixel accurate PDF recreation
- HTML email-safe layout
- Clickable website link
- Clickable phone number
- WhatsApp integration
- Google Maps location link
- Social media profile links
- Optimized images for email usage

## Technologies Used

- HTML5
- Inline CSS
- Email Table Layout

## Tested On

- Gmail
- Desktop Email Clients
- Mobile Devices

## Conversion Process

1. Analyze original PDF design
2. Extract logo and icons
3. Recreate layout using HTML
4. Add clickable hyperlinks
5. Optimize images
6. Test email rendering
